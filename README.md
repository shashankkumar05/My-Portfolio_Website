# 🌐 Personal Portfolio Website

A modern, responsive and interactive **Personal Portfolio Website** built to showcase my skills, projects, experience and web development journey.

The portfolio is designed with a clean dark-themed interface, animated backgrounds, smooth scrolling, interactive UI elements and responsive layouts to provide a polished experience across desktop, tablet and mobile devices.

## 📌 About The Project

This portfolio website represents my profile as a **Full Stack Web Developer** and provides a central place to explore my technical skills, projects and contact information.

The website focuses on:

- Clean and modern UI
- Responsive web design
- Interactive animations
- Smooth navigation
- Project showcase
- Skills presentation
- Contact section
- Mobile-friendly navigation

The website includes a contact section where visitors can enter:

- Name
- Email
- Subject

The frontend provides form interaction, loading feedback and a success message after submission.

> **Note:** The current contact form uses frontend JavaScript to simulate submission and does not include a backend email/API integration yet.

## 📱 Responsive Design

The website is optimized for different screen sizes:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

The navigation automatically changes to a mobile hamburger menu on smaller screens, while project and skill layouts adapt according to the available screen width.

## ⚙️ Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/shashankkumar05/your-repository-name.git
```

### 2. Open the project

```bash
cd your-repository-name
```

### 3. Run the website

Since this is a frontend project, no backend installation is required.

Simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for a better development experience.
